## Overview

The Ethereum smartcontracts in this module implement the [BlueSky prime field][bluesky] used in
Starkom and several Poseidon1 instances over the same field with state widths T=3, T=4, and T=5,
each with both the x^5 and the x^7 S-box.

[bluesky]: https://crates.io/crates/starkom-bluesky
